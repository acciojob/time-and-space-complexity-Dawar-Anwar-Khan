The concepts of Time, Space and Complexity.

Time complexity is a fundamental concept in computer science that measures the amount of time an algorithm takes to run as a function of the length of its input. Instead of measuring actual clock time—which changes depending on the processor, operating system, and programming language—time complexity focuses on how the number of required operations grows as the data size increases. Analyzing this growth rate allows developers to mathematically determine how efficient an algorithm is and predict how it will perform under heavy workloads.

Space Complexity is a metric that measures the total amount of memory or storage space an algorithm requires to run to completion as a function of its input size O(n). It is fundamentally analyzed using Big O notation to evaluate how memory usage scales under worst-case scenarios
